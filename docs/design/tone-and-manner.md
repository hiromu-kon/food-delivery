# トンマナ

## 性格

| キーワード | 意味                                                       | 画面での表れ方                                               |
| ---------- | ---------------------------------------------------------- | ------------------------------------------------------------ |
| 顔が見える | 大手のサービスではなく、地域のお店とその人たちを主役にする | 店名を看板のように大きく見せる。店舗の写真と紹介文を省かない |
| 迷わせない | 年齢や慣れに関係なく、次に何をすればよいかが一目でわかる   | 1 画面の主な操作は 1 つ。ボタンの文言は動作で書く            |
| 実直       | 盛らない。届く時間や金額を、確かなことだけ伝える           | 予測できない時間は出さない。金額は内訳まで見せる             |

## 方向性：のれん

地域の飲食店の入口にかかる「のれん」を、ブランドの象徴にする。藍色の布に白で店名を染め抜いた姿は、店がいま開いていることと、その店らしさを同時に伝える。

- 店舗のページの上部に、藍色ののれん（下端に切れ目のある帯）を置き、店名を明朝体で載せる。ここだけを大胆にし、ほかは落ち着かせる。
- 主な色は藍。差し色の「提灯の黄」は、カートの点数や「受付中」など、数や状態を示す小さな面積にだけ使う。
- 背景は白と冷たい灰色。料理の写真の色を邪魔しないため。

### 検討して採らなかった案

| 案                                         | 採らなかった理由                                                               |
| ------------------------------------------ | ------------------------------------------------------------------------------ |
| 食欲を誘う赤・オレンジを主色にする         | 大手のデリバリーサービスと見分けがつかない。地域のサービスとしての個性が出ない |
| 生成り（クリーム色）の背景と明朝体の見出し | 「手作り・和」の表現として定番すぎ、料理の写真の白とも濁る                     |
| 黒の背景と鮮やかな 1 色                    | 夜の飲食店には合うが、昼の定食屋やパン屋が多い地域の店舗と合わない             |

## 文字

- 画面全体は **Zen Kaku Gothic New**。丸すぎず硬すぎず、年配の人にも読みやすい。
- 店名とブランドのロゴにだけ **Zen Old Mincho** を使う。のれんに染め抜いた文字の印象を出すため。本文や操作には使わない。

## 文言のルール

### ボタン

- 必ず動作で書く。「注文を確定する」「カートを見る」「お届け先を追加する」。名詞だけ（「カート」）や「OK」「はい」は使わない。
- 同じ操作は、流れの中で同じ言葉を使う。「注文を取り消す」を押したあとのお知らせは「注文を取り消しました」。
- ダイアログで 2 つのボタンを並べるときは、実行する側を右に置く。取り消し・削除などの元に戻せない操作だけ、危険のボタン（赤）にする。

### 言葉づかい

- 注文者向けは「です・ます」。過度な敬語（「〜させていただきます」）は使わない。
- 店舗・配達員・運営向けは、短く言い切る（「受け付ける」「受け取った」）。現場で一目で読めることを優先する。
- システムの言葉ではなく、利用者の言葉を使う。「オーソリ」ではなく「お支払いの確保」、「ステータス」ではなく「状況」。用語は [用語集](../requirements/glossary.md) に合わせる。

### 数字

| 対象 | 書き方                                   | 例               |
| ---- | ---------------------------------------- | ---------------- |
| 金額 | 円記号を前に付け、3 桁ごとにカンマ。税込 | ¥1,960           |
| 距離 | 小数 1 桁の km。1 km 未満は m            | 1.2 km、800 m    |
| 時間 | 残り時間は分で。時刻は 24 時間制         | あと 8 分、18:30 |
| 数量 | 「点」で数える                           | 2 点             |

### エラーと空の状態

- 何が起きたかと、どうすればよいかを書く。謝らない。「このお店は今、注文を受け付けていません。ほかのお店を選んでください。」
- 空の状態は、次の行動につなげる。「まだ注文はありません。近くのお店を見てみましょう。」と、店舗一覧へのボタンを置く。

## 写真

- 料理の写真は、店舗が自分で撮ったものをそのまま使う。加工やフィルターで統一しない（お店の顔を見せるため）。
- 写真がない商品は、灰色の面に料理のアイコンを置く。ほかの店舗の写真やストック写真で埋めない。
- 写真の角丸は 12px。画面の端まで広げるのは、店舗ページ上部の写真だけ。

## 避ける表現

AI が作る画面によくある組み合わせで、このサービスの性格と関係のないもの。

- クリーム色の背景にテラコッタ色の差し色
- 同じ角丸・同じ影のカードをただ並べる構成。一覧は区切り線のリストを基本にし、カードは店舗一覧の写真付きの項目に限る
- 見出しの上に付ける英字の大文字ラベル、見出しの一語だけ色や書体を変える強調
- 説明文を中黒（・）でつないだ一行。項目ごとに分けて見せる
- 飾りのためのグラデーション、項目ごとに出てくるアニメーション
- ボタンの文言の後ろに付ける矢印（→）
