# コンポーネント

MVP の画面に必要な部品だけを作る。見た目と状態は Penpot の「03 コンポーネント」ページが正本。ここには使い分けを書く。名前は Penpot と実装で同じにする。

実装は shadcn/ui（アプリは React Native Reusables）を土台にする（[docs/architecture.md](../architecture.md)）。種類の名前が shadcn と違うものは、次のように対応させる。

| Penpot           | shadcn/ui                             |
| ---------------- | ------------------------------------- |
| Button primary   | Button `default`                      |
| Button secondary | Button `outline`                      |
| Button ghost     | Button `ghost`                        |
| Button danger    | Button `destructive`                  |
| Toggle           | Switch                                |
| NoticeBanner     | Alert                                 |
| Toast            | Sonner                                |
| BottomSheet      | Drawer（Web）・Bottom Sheet（アプリ） |
| SideNav          | Sidebar                               |

## 操作

| 名前              | 種類・状態                                                                               | 使い分け                                                                                            |
| ----------------- | ---------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `Button`          | primary / secondary / ghost / danger。大（48）・中（40）。通常・ホバー・無効・読み込み中 | primary は 1 画面に 1 つ（その画面の主な操作）。danger は確認のダイアログの中だけ。文言は動作で書く |
| `IconButton`      | 塗り / 枠なし。通常・無効                                                                | 戻る・閉じるなど、アイコンで意味が通じる操作だけ。読み上げ用の名前を付ける                          |
| `QuantityStepper` | 通常・最小（1）・最大（20）                                                              | カートの数量。1 のときの「−」は「カートから外す」になる（R-03）                                     |
| `AddButton`       | 通常・無効                                                                               | 商品をカートに入れる丸いボタン。商品の写真の右下に重ねる                                            |

## 入力

| 名前        | 状態                       | 使い分け                                                                     |
| ----------- | -------------------------- | ---------------------------------------------------------------------------- |
| `TextField` | 通常・入力中・エラー・無効 | ラベルを必ず上に置く。エラーは欄の下に、直し方まで書く                       |
| `Select`    | 通常・開いた状態・無効     | 選択肢が 5 つ以上のとき。4 つ以下なら `RadioGroup` や `Tabs` を検討する      |
| `Toggle`    | オン・オフ・無効           | すぐに反映される切替（売り切れ、稼働中、受付中）。保存ボタンと組み合わせない |
| `Checkbox`  | オン・オフ・無効           | 保存ボタンで確定する選択                                                     |

## 表示

| 名前          | 種類                                                     | 使い分け                                                           |
| ------------- | -------------------------------------------------------- | ------------------------------------------------------------------ |
| `StoreNoren`  | —                                                        | 店舗ページの上部だけに置く、ブランドの見せ場。ほかの場所で使わない |
| `StoreCard`   | 通常・受付停止中                                         | 店舗一覧の 1 件。写真付きのカードはこれだけにする                  |
| `MenuItem`    | 通常・売り切れ・写真なし                                 | メニューの 1 品。区切り線で並べ、カードにしない                    |
| `StatusLabel` | 受付待ち・調理中・準備完了・配達中・配達完了・キャンセル | 注文の状態の表示。色だけに頼らず必ず文字を入れる                   |
| `Tag`         | 中立・注意                                               | 受付停止中・売り切れなど、項目に付く短い補足                       |
| `CountBadge`  | —                                                        | 数だけを示す（カートの点数、新しい注文の数）                       |
| `OrderSteps`  | 5 段階のうち現在の位置                                   | 注文者の注文状況の画面だけで使う                                   |
| `ListItem`    | 通常・右に矢印・右に値                                   | 設定や履歴などの一覧の 1 行                                        |
| `Table`       | 見出しの行・本文の行・空                                 | 運営と店舗のパソコン向けの一覧。スマートフォンの画面では使わない   |

## お知らせ

| 名前           | 種類               | 使い分け                                                           |
| -------------- | ------------------ | ------------------------------------------------------------------ |
| `NoticeBanner` | 情報・注意・エラー | 画面にとどまる状態の説明（最低注文金額に届いていない、受付停止中） |
| `Toast`        | 完了・エラー       | 操作の結果を数秒だけ伝える。読まないと困る内容には使わない         |
| `Spinner`      | —                  | 読み込み中。1 秒未満で終わるものには出さない                       |
| `EmptyState`   | —                  | 一覧が空のとき。次の行動のボタンを必ず置く                         |

## 移動

| 名前        | 種類                     | 使い分け                                                 |
| ----------- | ------------------------ | -------------------------------------------------------- |
| `AppHeader` | 戻るあり・なし、右に操作 | スマートフォンの画面の上部                               |
| `TabBar`    | 3 項目、選択中           | 注文者アプリと配達員アプリの下部                         |
| `SideNav`   | 項目、選択中             | 店舗と運営のパソコン向けの画面の左側                     |
| `Tabs`      | 下線、選択中             | 同じ画面の中の切替（メニューのカテゴリ、注文一覧の状態） |
| `CartBar`   | —                        | カートに商品があるときだけ、店舗ページの下部に浮かせる   |

## 重ねて出すもの

| 名前          | 種類                   | 使い分け                                                             |
| ------------- | ---------------------- | -------------------------------------------------------------------- |
| `Dialog`      | 確認・危険な操作の確認 | 元に戻せない操作の前の確認だけ。ボタンは実行する側を右に置く         |
| `BottomSheet` | —                      | スマートフォンで、画面を離れずに選ぶ・入力する（お届け先の切替など） |
