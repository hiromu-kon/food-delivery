# プライバシーポリシー

> 仮の文面です。事業者名・住所・連絡先・日付は決まっていません。公開する前に、弁護士などの専門家の確認を受けてください。

株式会社〇〇（以下「当社」）は、フードデリバリーサービス「Food Delivery」（以下「本サービス」）で取り扱う個人情報を、個人情報の保護に関する法律その他の法令に従い、次のとおり取り扱います。

## 1. 取得する情報

| 対象   | 情報                                                                                                                 |
| ------ | -------------------------------------------------------------------------------------------------------------------- |
| 会員   | 氏名、メールアドレス、電話番号、パスワード（復元できない形で保存します）、お届け先の住所と位置、配達メモ、注文の履歴 |
| 支払い | 決済代行会社が発行する決済の識別番号（カード番号は当社では受け取りません）                                           |
| 配達   | 置き配のときに配達員が撮影する、商品を置いた場所の写真                                                               |
| 利用   | 本サービスを利用した日時、端末の種類、IP アドレスなどの記録                                                          |

## 2. 利用の目的

当社は、取得した情報を次の目的で利用します。

1. 注文の受け付け、店舗への伝達、配達の手配、代金の請求と返金
2. 会員の本人確認と、アカウントの管理
3. 注文や配達に関する連絡、お問い合わせへの対応
4. 不正な利用の防止と、規約に違反した場合の対応
5. 本サービスの改善と、利用状況の分析（個人を特定しない形にして行います）

## 3. 第三者への提供

当社は、次の場合を除き、会員の同意なく個人情報を第三者に提供しません。

1. 注文を届けるために、必要な範囲の情報を店舗と配達員に伝える場合
   - 店舗には、注文の内容を伝えます
   - 担当の配達員には、氏名、電話番号、お届け先の住所、配達メモを伝えます。担当が決まる前は、お届け先の町名と距離だけを伝えます
2. 法令に基づく場合、または人の生命・身体・財産を守るために必要で、同意を得ることが難しい場合

## 4. 取り扱いの委託

当社は、利用の目的の範囲で、個人情報の取り扱いを次の事業者などに委託します。委託先は適切に監督します。

| 委託する業務             | 委託先                             |
| ------------------------ | ---------------------------------- |
| クレジットカードの決済   | Stripe, Inc.（米国）               |
| 住所から位置を求める処理 | 地図サービスの事業者（未定）       |
| メールの送信             | メール配信サービスの事業者（未定） |
| データの保管             | クラウドサービスの事業者（未定）   |

外国の事業者に委託する場合は、その国の個人情報の保護に関する制度と、委託先が講じている措置について、本サービス上で情報を提供します。

## 5. 安全管理

当社は、個人情報の漏えい・滅失・毀損を防ぐため、アクセスできる人の制限、通信の暗号化、パスワードの復元できない形での保存などの措置を講じます。記録（ログ）には、氏名・住所・電話番号・メールアドレスを残しません。

## 6. 保存の期間

当社は、利用の目的に必要な期間、個人情報を保存します。退会した会員の情報は、法令で保存が求められる情報を除き、退会から 1 年以内に消去します。置き配の写真は、配達完了から 30 日後に消去します。

## 7. 開示・訂正・利用停止などの請求

会員は、当社が保有する自分の個人情報について、開示・訂正・追加・削除・利用の停止を請求できます。請求は、下記の窓口に連絡してください。本人であることを確認したうえで、法令に従って対応します。
