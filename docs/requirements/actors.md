# 要件定義：利用者

| 利用者       | 目的                                           | 主な場面                                           | 使うもの          | アカウントの作り方               |
| ------------ | ---------------------------------------------- | -------------------------------------------------- | ----------------- | -------------------------------- |
| 注文者       | 近くのお店の料理を届けてもらう                 | 自宅や職場で、スマートフォンやパソコンから注文する | Web・注文者アプリ | 自分で登録する（メールアドレス） |
| 店舗スタッフ | 届いた注文を受けて調理し、配達員に渡す         | 営業中の店内で、タブレットやパソコンを置いて使う   | Web（`/store`）   | 運営が発行する                   |
| 配達員       | 配達を受けて、店舗から注文者へ届ける           | 稼働中は自転車やバイクで移動しながら片手で使う     | 配達員アプリ      | 運営が発行する                   |
| 運営         | 店舗と配達員を管理し、注文のトラブルに対応する | 事務所のパソコンで使う                             | Web（`/admin`）   | 運営の管理者が発行する           |

- 店舗スタッフのアカウントは 1 つの店舗に属する。1 つの店舗に複数のスタッフがいてよい。
- 配達員アプリは移動中に使うため、大きなボタンと少ない操作で使えるようにする。
