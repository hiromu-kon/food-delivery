# 要件定義：用語集

画面の文言・コード・会話で同じ意味で使う。コード上の名前は英語で、ここに対応を書く。

| 用語           | コード上の名前      | 意味                                                                     |
| -------------- | ------------------- | ------------------------------------------------------------------------ |
| 注文者         | customer            | 料理を注文する人                                                         |
| 店舗           | store               | 料理を作る飲食店                                                         |
| 店舗スタッフ   | store staff         | 店舗の管理画面を使う人。1 つの店舗に属する                               |
| 配達員         | courier             | 店舗から注文者へ料理を届ける人                                           |
| 運営           | admin               | このサービスを運営する事業者の担当者                                     |
| お届け先       | delivery address    | 注文者が料理を受け取る住所。緯度・経度を持つ                             |
| 配達エリア     | delivery area       | 店舗が配達を受け付ける範囲。店舗からの距離で決まる（R-01）               |
| 配達メモ       | delivery note       | お届け先ごとに保存する、配達員への伝言（建物の入り方など）（R-15）       |
| 受け取り方法   | receiving method    | 手渡し（hand）か置き配（leave at door）か（R-15）                        |
| 置き配         | leave at door       | 注文者に会わず、指定の場所に商品を置いて配達を終えること（R-15）         |
| 商品           | menu item           | 店舗のメニューの 1 品                                                    |
| 売り切れ       | sold out            | 商品を一時的に注文できない状態                                           |
| 受付中・停止中 | accepting / paused  | 店舗が新しい注文を受けるかどうか（R-09）                                 |
| 小計           | subtotal            | 商品の価格 × 数量の合計                                                  |
| 配達料         | delivery fee        | 注文 1 件ごとにかかる配達の料金（R-02）                                  |
| 合計           | total               | 小計 + 配達料。注文者が支払う金額                                        |
| 受付期限       | acceptance deadline | 注文してから店舗が受け付けるまでの期限（R-06）                           |
| 配達待ち       | awaiting courier    | 店舗が受け付け、配達員がまだ決まっていない注文                           |
| 稼働中・休止中 | online / offline    | 配達員が配達を受けられる状態かどうか                                     |
| 仮売上         | authorization       | 注文時に、カードの利用枠を確保するだけで、まだ請求しない状態             |
| 売上確定       | capture             | 仮売上を実際の請求にすること。店舗の受付時に行う                         |
| 仮売上の取消   | void                | 仮売上を請求せずに取り消すこと（Stripe では PaymentIntent のキャンセル） |
| 返金           | refund              | 売上確定後に、支払われた金額を注文者に戻すこと                           |

注文の状態の名前は [docs/specs/order-status.md](../specs/order-status.md) を参照。
