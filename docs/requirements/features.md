# 要件定義：機能一覧

機能ごとに GitHub の親 Issue を 1 つ作り、提供先ごとに子 Issue に分ける。画面 ID は [docs/specs/screens.md](../specs/screens.md)、業務ルール ID は [docs/specs/business-rules.md](../specs/business-rules.md)。

## 注文者

| ---- | -------------------- | ------------------------------------------------------------------------ | ----------------- | ------------------- | ---------- | ------ |
| F-01 | 会員登録・ログイン   | メールアドレスとパスワードで登録・ログインする。パスワードを再設定できる | Web・注文者アプリ | S-C01〜S-C03, S-C11 | R-14       | MVP    |
| F-02 | お届け先の登録       | お届け先の住所を登録・変更・削除する                                     | Web・注文者アプリ | S-C10               | R-01       | MVP    |
| F-03 | 店舗を探す           | お届け先が配達エリアに入る店舗を一覧で見る                               | Web・注文者アプリ | S-C04               | R-01, R-09 | MVP    |
| F-04 | メニューを見る       | 店舗のメニューをカテゴリごとに見る                                       | Web・注文者アプリ | S-C05               | R-10       | MVP    |
| F-05 | カート               | 1 つの店舗の商品をカートに入れ、数量を変える                             | Web・注文者アプリ | S-C05, S-C06        | R-02, R-03 | MVP    |
| F-06 | 注文・支払い         | お届け先とカードを指定して注文する                                       | Web・注文者アプリ | S-C07               | R-02〜R-06 | MVP    |

| F-08 | 受付前のキャンセル   | 店舗が受け付ける前の注文を取り消す                                       | Web・注文者アプリ | S-C08               | R-07       | MVP    |
