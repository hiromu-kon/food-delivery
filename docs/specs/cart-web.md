# Web のカート（F-05 / S-C05・S-C06）

## 操作と遷移

店舗メニュー `/stores/:storeId/menu` から商品を1点ずつ追加する。同じ商品への追加は数量を加算し、1商品20点を上限とする。売り切れの商品は表示を残し、追加ボタンを表示しない。操作側でも売り切れ商品の追加を拒否する。カート復元前は追加を無効にする。

商品があるとき、メニュー下部に数量の合計・小計を示す CartBar を表示する。押すと `/cart`（S-C06）へ進む。共通ナビゲーションの「カート」からも移動できる。

別店舗の商品を追加しようとした場合、AlertDialog で今の商品を外してよいか確認する。「入れ替える」で確定した場合のみ新店舗の商品1点に置き換える。キャンセル・Escapeでは保存内容を含め元のカートを保持する。

S-C06には店舗名、メニューへ戻るリンク、商品名・写真・税込単価・数量・商品ごとの金額を表示する。QuantityStepperで1〜20点へ変更し、1点のときの削除操作で商品を外す。最後の商品を外すと空状態になり、「お店を探す」から店舗一覧へ戻れる。

## 金額と保存

`@repo/domain` のカート操作・金額計算・最低注文金額判定を使う。配達料は一律300円、空カートは0円とする。最低注文金額は配達料を含まない小計で判定し、不足額を表示する。最低金額を満たす状態も明示する。

カートは認証済みユーザーIDごとの `food-delivery:cart:v1:<userId>` キーでlocalStorageへ操作ごとに保存し、再読み込み・画面移動後も復元する。商品と店舗の表示名・商品写真URL・店舗の最低注文金額を同じデータに保存する。未知のバージョン、破損JSON、店舗混在、重複商品、不正数量・金額は復元せず空状態へ戻す。復元値の形を検証してからドメイン関数でも検証する。保存・読込が拒否された場合は操作を継続できるが、復元・保存できない旨を画面に案内する。複数タブ間の即時同期は行わない。

保存した単価・最低注文金額は表示用のスナップショットであり、同商品をメニューから再追加したときは取得済みの単価・店舗情報へ更新する。注文時に必要な最新在庫・受付状態・価格の再取得とAPIでの再計算はF-06以降の責務とする。
