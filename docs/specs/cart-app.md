# 注文者アプリのカート（F-05 / S-C05・S-C06）

`origin/issue22-menu-app` のメニューから商品を1点ずつ追加し、`/cart` で数量変更・削除を行う。店舗検索の「カートを見る」からも空状態を含めて開ける。売り切れは価格とラベルを残し、追加ボタンを出さない。受付停止店舗の追加も無効にする。同商品の追加は20点までで、数量1の減少は削除、20点の増加は無効。数量・金額・店舗切替の判定には `@repo/domain` の関数を使う。

別店舗の追加では、現在の店舗名とカートを空にする旨を示した確認ダイアログを開く。「入れ替える」で明示的に確定した場合だけ、domain の `confirmRestaurantChange` を指定して新店舗の商品1点へ置き換える。「キャンセル」・OSの戻る操作は変更も保存もしない。

カートの商品ID・店舗ID・税込単価・数量、表示用の商品名・任意写真・店舗名・最低注文金額を、端末の AsyncStorage `customer.cart.v1` にバージョン付きJSONで保存する。端末内のカートであり、ログアウトやアプリ再起動でも保持し、サーバーや別端末とは同期しない。認証トークンは含めない。復元中と保存中は変更操作を無効にし、保存成功後に画面を更新する。保存失敗は直前のカートを保持し、エラーを示して再操作できる。読込失敗は内容を上書きせず再試行を出す。不正JSON・店舗混入・重複商品・不正な数量や金額・表示情報との不整合は空カートとして保存し直し、案内する。

S-C05のCartBarはスクロール領域の下に置き、全商品の点数と小計を表示する。S-C06は店舗名、64pxの商品写真（未設定は代替表示）、商品名、行合計と税込単価、QuantityStepper、小計・配達料・合計を表示する。空カートは配達料を含め0円で、「カートは空です」と店舗検索への導線を出す。最低注文金額との比較は配達料を含めず、不足額を表示する。条件を満たす場合も、このF-05では注文内容の確認を準備中としてボタンを無効にする。注文作成・決済・S-C07への遷移は実装しない。

価格・最低注文金額は取得したメニューのスナップショットで、同店舗へ再追加した際に対象商品の単価・名前・写真と店舗情報を更新する。保存後の在庫・受付状態・価格の再検証と注文金額の確定は将来の注文APIの責務であり、ローカルカートを注文の正本にしない。

PenpotのS-C05 `b5f6bdf2-dac1-8004-8008-d825d1f5751f` とS-C06 `f7317e8b-ba0b-8007-8008-d8bfae370fcf` の実JSONを照合。既存AddButton・CartBar・QuantityStepper、背景/文字/境界線トークン、余白16px・行間12px、写真64px、下部ボタンを使う。S-C06のデザインには「注文の確認」「注文を確定する」とあるが、この段階のスコープに合わせタイトルを「カート」、ボタンを「注文内容の確認へ（準備中）」とする。内容が長い場合は伸長・折返し・スクロールを許容し、既存nativeのsafe areaと下部タブを保持する。
